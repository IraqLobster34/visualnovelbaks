# УВС-19F: Причина отказа

Линейная визуальная новелла для Windows на Ren’Py. Ларри Бакс приходит в кабинет Молли Брандо, чтобы выяснить причину отказа в повышении. В разговор вмешивается новый начальник ОВС Александр Морэ.

В игре весь предоставленный автором текст: 661 реплика и ремарка, 552 озвученные реплики четырёх персонажей, одна последовательность событий. Финал включает разговор Брандо с Морэ и звонок секретаря.

## Скачать и играть

Откройте [Releases](https://github.com/IraqLobster34/visualnovelbakshuesos/releases), скачайте Windows ZIP, распакуйте его полностью и запустите `Uvs19F.exe`. Установка движка, Python и подключение к интернету игроку не нужны.

Клик / пробел / Enter — дальше; колесо вверх — назад; Esc — меню; H — скрыть интерфейс; F — полный экран. Сохранения, история, повтор голоса и автоматическое чтение доступны в нижней панели. Режим «Авто» ожидает завершения озвучки.

Иллюстрации и голоса созданы ИИ. В тексте есть ненормативная лексика.

## Проект Ren’Py

Папка `game/` содержит готовый игровой проект. Для редактирования откройте его через Ren’Py SDK 8.5.3.

Персонажи нарисованы по авторскому референсу. Сюжет не содержит вариантов выбора или альтернативных концовок.
